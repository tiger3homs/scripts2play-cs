### **🚀 Server Manager V3 is Here! 🚀**

Hey everyone! A major update to the **CS Server Manager** script is now live, packed with new features to make managing your servers on play-cs.com even easier.

Here's what's new in **Version 3**:

*   **✨ Custom Presets:** You can now save your own server configurations! Set up a server exactly how you like it, click **"Save as Preset,"** give it a name, and you can instantly apply those settings to any server later. You can also delete presets you no longer need.

*   **📋 Copy Server Info:** A new **"Copy Link"** button has been added. One click copies the server's join link and PIN to your clipboard, perfect for quickly sharing with friends.

*   **🎨 UI Polish:** The action buttons now have icons, and the overall interface has been cleaned up for a smoother, more intuitive experience.

*   **⚙️ Better Performance:** The script has been refactored under the hood to be faster and more reliable.

Get the latest version and supercharge your server management!

**Install/Update Here:** https://github.com/tiger3homs/scripts2play-cs/raw/main/ServerManager/v3/v3.user.js
